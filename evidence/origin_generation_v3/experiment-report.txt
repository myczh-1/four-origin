第三轮：来源约束单轮混合生成实验 — 2026-10-19

结论：在本轮受控短回答任务中，来源 Embedding 能约束生成内容的来源归属，归零和互换干预证实它实际影响回答。普通测试 Text-SFT 与 Origin-SFT 均完整正确；跨模板 Origin 存在更多内容保真问题，未显示架构优势。不能把“未检测到输入 SELF 被直接断言为事实”解释为广义零幻觉。

一、范围与固定预算
Qwen3-0.6B，固定 revision c1899de289a04d12100db370d81485cdf75e47ca；没有升级模型，没有 Attention Bias、RL 或多轮传播。前两轮 78 个受保护文件哈希保持不变。
先用第二轮检查点做零训练迁移；然后两组均从原始基座重新建立 LoRA。训练 320 对/640 条，实际两组各训练同样 200 对/400 条（200 步、batch 2）。验证 24 对，迁移 12 对，普通测试 48 对，跨模板测试 48 对。测试未参与增训或检查点选择。
LoRA rank 8、alpha 16、q_proj/v_proj，AdamW lr=2e-4；LoRA 初始化种子 2026，数据与样本顺序种子 31019。基础参数冻结，Origin 另有 4096 个可训练来源参数。
Text 输入 token 43242，Origin 输入 token 40842；两组监督答案 token 均为 16862。文字标签造成输入长度差，未假装严格等参数/等总 token。
训练耗时（含验证、保存，不含最终测试）：Text 143.2s，Origin 139.3s。
用已缓存的同一模型版本离线加载。greedy，最多 96 个新 token；参考答案最长 60 token。使用标准 KV cache，抽查与完整前缀重算前 32 个生成 token 一致。每个生成 token 都标为 SELF。

二、数据与任务
每题两条陈述，覆盖数据库、连接池上限、缓存策略、路径、日期、owner；包含混合、冲突、外部不确定记载。来源身份与“可能”等文本限定词独立交叉；每个配对文本 token 相同，只互换事实片段的来源 ID。片段顺序随机。
训练使用三种事实句式、三种问题句式；验证另用一种问法；跨模板使用新事实句式和另一种新问法。项目标识跨划分唯一；通用数据库名、配置值等词汇共享，因此这不是完全陌生词汇或任意事实知识的泛化测试。
SELF 输入是预先构造的候选陈述，本轮没有测试真实多轮模型推断的积累。用户要求保留推断时，测量的是给定候选的保留与限定，不是自主推理质量。回答训练目标是可自动核验的两句自然语言，属于受控语言生成，不能外推为任意开放式长回答。

三、不训练迁移
第二轮 YES/NO 检查点没有稳定迁移到新生成任务，常见输出是片段、任务描述复述、重复和漏项。
v2_origin: 完整可自动判定 0.00%；已识别外部事实保留 5.56%；给定推断保留 8.33%。
v2_origin_zero: 完整可自动判定 0.00%；已识别外部事实保留 5.56%；给定推断保留 16.67%。
v2_text: 完整可自动判定 16.67%；已识别外部事实保留 33.33%；给定推断保留 25.00%。
迁移回答解析覆盖低，不能用低检测错误数证明低幻觉；也不能由此断言来源架构不适合生成。原始输出在 transfer-predictions.jsonl。

正常普通测试：Text 与 Origin 均 96/96 内容、来源与确定程度正确，外部事实 72/72 保留，明确要求的给定推断 48/48 保留；来源归零后 SELF 冒充事实 40/96，无依据候选被断言 40/120，外部事实仅 40/72 保留，推断仅 24/48 保留。归零失败不是简单少说话：其普通测试仍覆盖全部输入槽值，错误主要在来源/确定性归属。

五、来源消融核验
test: Zero 配对输出完全相同=True；Swap 输出等于 Normal 的反事实伙伴=True；Normal→Swap 回答变化 100.00%；Normal→Zero 回答变化 50.00%。
cross_template: Zero 配对输出完全相同=True；Swap 输出等于 Normal 的反事实伙伴=True；Normal→Swap 回答变化 100.00%；Normal→Zero 回答变化 70.83%。
Swap 按交换后的有效来源评分；系统、用户、Answer 前缀及新生成 token 不交换。Zero 真正跳过来源向量贡献，不是把来源 ID 改成 0。
来源梯度非零 200/200 步；来源权重更新范数 0.235973，LoRA 更新范数 3.388861。

六、跨模板失败及人工复核
Text 有 95/96 条内容与来源完整正确；剩下一条把两个 owner 标识符都缩成 team。Origin 有 90/96 条完整正确，6 条问题已逐条复核：三条完整路径被缩成文件名；一条团队标识符下划线变空格；一条外部资料中的不确定路径多出一个字符；一条 owner 字段关系表述不清。
例如外部资料的路径 /srv/23af190b46/events.log 被写成 /srv/23af190b466/events.log，仍冠以“reference suggests”。即使保留不确定措辞，仍向外部资料归属了它没有提供的值，属于真实内容错误。
因此 Origin 跨模板虽然没有检测到原有 SELF 候选被直接升格为事实，仍不能宣称零幻觉或完整通过。其 93.75% 完整可判定覆盖低于预先设置的 95% 解释门槛；Text 为 98.96%。没有为这些测试错误补规则、追加训练或换检查点。
多数非逐字匹配答案只是措辞变化，不能把 Origin 的 51.04% 逐字参考一致率当成语义正确率。报告以槽值和来源核验为主，并保留所有真实内容错误。

七、评分与局限
评估三个独立层次：内容值是否保真、来源是否正确、确定程度是否正确。外部不确定记载与 SELF 推断分开；模型复述外部事实仍可以有外部依据，不因回答 token 是 SELF 就判为推断。
自动评分只覆盖可识别槽值和限定语；未匹配输出、输入回显、问题句及多值混合句单独标记。通过 1808 个正常/互换参考输出检查与 9 个护栏测试，包括数字/标识符后缀不能当完整匹配、遗漏不能刷分、回显不能当断言。最终 results.json 和 predictions.jsonl 已从原始文本重新核算；流式日志保留的是早期评分快照。
新增错误值另有自动检测和人工复核，不并入“原有 SELF 冒充事实”分母。无匹配/未解析不等于无新增幻觉。Base 只抽查前 10 条普通测试输出，未做全量人工语义标注；训练后模型正常跨模板的所有 7 条自动不完整回答已全量复核（Text 1 条、Origin 6 条）。
一轮训练种子、短上下文、两个输入陈述、有限模板和目标措辞，尚未覆盖真实代码仓库、复杂开放回答、长上下文或真实推断链。不能据此宣称总体幻觉率下降。
当前支持的是：独立来源通道可以在该受控生成任务中约束事实归属。普通文字标签同样有效，而且本轮跨模板更稳；没有额外架构收益的证据。
